THE SCIENCE BEHIND THE INVESTIGATION

Data structures aren't abstract textbook puzzles — they are the architectural backbone required to categorize forensic evidence, traverse human social networks, and reconstruct crime timelines under strict logical constraints.

PHASE 01 Ο(1) / Ο(n)

Linear Structures

Linked Lists • Stacks • Queues • Expression Evaluator

DSA PRINCIPLES:

Sequential memory chaining, Last-In-First-Out (LIFO) stacks for state management, and First-In-First-Out (FIFO) queues for orderly item processing.

INVESTIGATION APPLICATION:

Organizing raw evidence items in a dynamic Linked List, maintaining an Action History Stack with full Undo/Redo capability for detective actions, and sequencing Witness Interview Queues.

PHASE 02 Ο(log n) / Ο(V + E)

Trees & Graphs

Binary Trees • Binary Search Tree (BST) • Graph Adjacency List • BFS • DFS

DSA PRINCIPLES:

Hierarchical decision trees, ordered BST storage supporting duplicate keys, and relational adjacency lists traversed via Breadth-First and Depth-First searches.

INVESTIGATION APPLICATION:

Classifying physical vs testimonial evidence, indexing suspects by suspicion score in a BST (with duplicate key preservation), and exploring social ties via Queue-based BFS to calculate degrees of separation from the victim.

PHASE 03 Ο(n log n)

Searching & Sorting

Linear Search • Binary Search • Insertion Sort • Merge Sort • Quick Sort

DSA PRINCIPLES:

Comparison-based element ordering, divide-and-conquer partitioning, and logarithmic search on monotonic ordered arrays.

INVESTIGATION APPLICATION:

Rapid clue lookup by name (Ο(n)) versus exact numeric importance (Ο(log n) Binary Search), benchmarked against Insertion, Merge, and Quick Sort with live comparison and swap/move telemetry counters.

PHASE 04 Ο(n!) → Pruned

Backtracking Engine

State Space Search • Early Branch Pruning • Constraint Satisfaction

DSA PRINCIPLES:

Systematic recursive exploration of permutation trees, abandoning whole invalid subtrees immediately when a constraint is broken (backtracking step).

INVESTIGATION APPLICATION:

Reconstructing the valid chronological crime timeline from unordered events while strictly enforcing before, mustFollow, and notAdjacent forensic rules — or proving an alibi impossible.
